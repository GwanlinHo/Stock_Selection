# 台股選股深度分析報告 2026-06-07

> 本報告聚焦「最終精選池」：於本週掃描中**同時通過 L3（法人籌碼淨買超）與 L4（基本面：營收 YoY 與年化 ROE）兩道過濾**的標的，共 **79 檔**。以下內容結合籌碼、估值與產業趨勢，進行去罐頭化的交叉解讀，並特別標註指標之間的矛盾與潛在風險。

---

## 一、宏觀趨勢：精選池高度集中於「AI 硬體供應鏈」

本期 79 檔精選池的產業分佈呈現極端的一面倒：

| 群組 | 檔數 | 代表 |
| :--- | :---: | :--- |
| 電子零組件業 | 18 | 華新科、興勤、康舒、台燿、晶技 |
| 電腦及週邊設備業 | 12 | 緯創、英業達、樺漢、事欣科 |
| 半導體業 | 11 | 力積電、景碩、頎邦、矽力*-KY |
| 其他電子業 | 5 | 鴻海、漢唐、亞翔、致茂 |
| 光電 / 電子通路 / 通信 / 資訊服務 | 16 | 玉晶光、益登、啟碁、精誠 |
| 傳產與其他（化工、鋼鐵、航運、生技、金融…） | 17 | 大成鋼、萬海、和桐、藥華藥 |

電子相關產業合計 **62 檔，佔比約 78%**。這不是隨機分佈，而是一條清晰的主軸：**法人資金正沿著「AI 資料中心」的實體建置鏈，由上游往下游全面卡位**。值得注意的是，本週訊號最強的不是傳統的晶片設計，而是三個「賣鏟子」的環節：

1. **機房代工與組裝（下游放量）**：鴻海、緯創、英業達三大代工廠同時出現在籌碼買超前段班，且營收 YoY 全數雙位數成長。其中緯創 YoY 高達 112%，反映 AI 伺服器整機（含 GB 系列機櫃）出貨進入陡升期，已從「拉貨預期」走向「實質認列」。

2. **無塵室與機電工程（建廠潮）**：漢唐（YoY 102%）、亞翔（YoY 71%，ROE 居前段）兩檔無塵室統包商雙雙入選。這是領先指標——它們的在手訂單，等於是先進製程與資料中心**未來 1～2 年資本支出的提前兌現**，代表這波擴產並非短打。

3. **被動元件與電源（漲價循環重啟）**：電子零組件業以 18 檔居冠，華新科、興勤、康舒、晶技、信音、千如等集體上榜。MLCC、電感、電源管理在 AI 伺服器「料號數量倍增 + 規格升級」的帶動下，正從谷底走出新一輪漲價與庫存回補循環。

相對地，**記憶體與晶圓代工**的訊號最為激進：力積電以淨買超 31 萬張（單位：千股）高居全池籌碼之冠，YoY 58.9%，顯示資金對記憶體報價落底反彈與成熟製程稼動率回升的押注力道極大。

**傳產的少數倖存者更值得玩味**：大成鋼（鋼鐵，淨買超 7.8 萬張、PER 僅 12.8）、萬海（航運，PER 全池最低 8.0）、和桐（化工，YoY 84.8%）能在電子海嘯中突圍，代表它們各自有獨立題材（美國基建用不鏽鋼、運價反彈、特用化學），與電子股形成低相關，具備資產配置上的避震價值。

## 二、核心標的深度點評（兼顧籌碼、估值、題材三軸）

> 篩選邏輯：在 79 檔中，優先挑出「**法人籌碼明確 + 估值不貴（低 PER/PEG）+ 題材具延續性**」三軸交集者，這才是真正的 A 級潛力，而非單純營收數字漂亮。

### 1. 緯創（3231）— 本期綜合評分最高
PER 17.1、PEG 0.26、營收 YoY 112%、法人淨買超 1.34 萬張。這是一個罕見的「高成長卻便宜」組合：市場願意給予的本益比仍停留在傳統代工水準（17 倍），但其營收動能（翻倍）已是成長股等級。**矛盾點即是機會點**——若 AI 伺服器毛利率能站穩，當前估值對成長性存在明顯折價。風險在於 GB 機櫃的良率與認列節奏，單季營收波動會放大。

### 2. 鴻海（2317）— 籌碼定海神針
淨買超 11.1 萬張為全池權值股之最，YoY 39.6%、PER 20.2。作為 AI 機櫃組裝的最大贏家，鴻海的角色是「**池中的 Beta 基準**」：它的法人買超代表的是大盤級別的資金態度，而非單一題材投機。PEG 1.16 屬合理，不便宜也不貴，適合作為核心持股而非彈性標的。

### 3. 樺漢（6414）／事欣科（4916）— 工業電腦的低基期補漲
樺漢 PER 17.8、ROE 270；事欣科 PER 21.4、PEG 僅 0.03、YoY 50.2。兩檔皆為鴻海集團工業電腦布局，估值相對主流伺服器股落後一截，屬於「同一題材、估值尚未反映」的遞延補漲族群。事欣科 PEG 0.03 顯示其 EPS 成長幅度遠大於股價漲幅，CP 值突出，但需留意其法人買超規模偏中型，籌碼安定度不及大型股。

### 4. 楠梓電（2316）— 全池最便宜的成長股
PER 10.8、PEG 0.08、YoY 74.3%、ROE 131。在精選池中估值最低且成長最猛的衝突組合。作為 PCB／載板供應商，營收倍增反映高階板需求外溢。**唯一警訊**是法人買超僅 1126 張、規模偏小，意味這是「基本面先動、籌碼尚未大舉跟進」的早期階段，適合作為觀察名單的優先候選，而非追高。

### 5. 漢唐（2404）／亞翔（6139）— 建廠潮的領先指標
漢唐 PER 22.4、YoY 102%；亞翔 PER 22.4、ROE 273、YoY 70.6。無塵室統包的特性是「**先有訂單、後有營收**」，因此它們的高成長具有較高的能見度與遞延確定性。這兩檔是判斷「這波 AI 資本支出是真擴產或假題材」的試金石——只要它們營收持續成長，就代表下游建置仍在加速。

### 6. 大成鋼（2027）— 電子池中的傳產異類
淨買超 7.86 萬張（全池第三）、PER 12.8、PEG 0.17、YoY 37.7%。在一片電子股中，鋼鐵股能吸引如此大額法人買超實屬異常，背後題材應為美國基建與資料中心機櫃結構件的不鏽鋼需求。低估值 + 大額籌碼 + 與電子低相關，是分散風險的優選。

### 7. 藥華藥（6446）— 精選池唯一生技
YoY 108.5%、PER 58.8、PEG 1.12、ROE 109.9。作為全池唯一的生技醫療標的，其入選代表新藥（紅血球增生性疾病用藥）的海外銷售已進入規模化放量。PEG 約 1.1 對生技股而言相當合理。這是一檔與景氣循環完全脫鉤的標的，適合作為投組中的獨立 Alpha 來源，但需承擔單一藥證的政策與專利風險。

## 三、指標矛盾與風險警示（務必交叉檢視，勿被單一數字誤導）

本期數據存在數個系統性的指標失真，若不校正，極易誤判。以下逐一拆解：

### [!] 風險一：ROE 普遍破百，屬計算口徑失真，不可作絕對值解讀
精選池中 ROE 動輒 100%～300%，極端者如慶騰（4783%）、吉祥全、輔信等更達數千%。此乃計算方法所致——系統採「**近四季 TTM 淨利 ÷ 最新一期股東權益**」年化推估，遇到減資、高財務槓桿、或業外一次性收益（如處分資產、匯兌）時會嚴重灌水。
**正確用法**：ROE 在此僅能作為「**相對排序**」參考（誰的資本效率相對高），絕不可解讀為真實的股東報酬率。慶騰 4783% 這類數字應直接視為雜訊剔除。

### [!] 風險二：營收 YoY 異常飆高者，多為「結算題材」而非常態成長
潤隆（6494%）、方土昶（886%）、台汽電（533%）、宏遠證（343%）的 YoY 高得不合常理。
- **潤隆**為建設股，營收隨建案完工一次性認列，單月暴衝是建商常態，不代表持續動能。
- **台汽電、宏遠證**則受低基期與業外（電廠、自營證券損益）放大。
**結論**：對這幾檔，應改看「在手建案 / 在建電廠 / 自營部位」的實質含金量，YoY 數字本身無分析意義。

### [!] 風險三：高 PER 與「被法人買超」並存——景氣循環股的甜蜜陷阱
系統電（PER 354）、景碩（PER 201）、台嘉碩（197）、千如（128）、康舒（128）出現「估值極貴卻仍被法人買進」的矛盾。
這通常是**景氣循環股獲利落底、分母（EPS）極小導致 PER 虛高**的典型現象——載板（景碩）、被動元件（康舒、千如）正處於獲利低基期，法人買的是「下一波循環向上的獲利彈性」，而非當下的便宜。
**風險點**：這類標的是「**賭未來獲利兌現**」，一旦下一季 EPS 未如預期跳升，PER 將無從收斂，回檔幅度會很猛。屬於高風險高彈性區，不宜重壓。

### [!] 風險四：PER 或 PEG 顯示為 0，是資料缺漏而非「免費的便宜」
菱生、聯穎、亞電、廣穎、光鼎等 PER 顯示 0，以及大量 PEG = 0 的標的，並非真的零本益比，而是**該檔 EPS 成長率或本益比資料在本期未能取得**，導致 PEG 無法計算。
**警告**：切勿將 PEG = 0 誤判為「極度便宜」。對這些標的，本期的估值面屬於「資訊不足」，應在補齊財報數據後再行評估，不可僅憑 L3／L4 通過就納入買進清單。

### [!] 風險五：小型股的籌碼安定度陷阱
部分基本面亮眼者（如楠梓電、百容、聯一光）法人淨買超規模僅數百至一千餘張。在小型股上，**單一法人的進出就能左右籌碼結構**，買超訊號的雜訊比偏高。對此類標的，建議將「法人連續買超天數」與「成交量是否同步放大」納入二次確認，避免單日籌碼的假訊號。

## 四、總結與操作層級建議

| 層級 | 特性 | 代表標的 |
| :--- | :--- | :--- |
| 核心配置（大型 + 籌碼穩 + 估值合理） | 趨勢確定、波動相對低 | 鴻海、緯創、英業達、大成鋼 |
| 彈性攻擊（成長猛 + 估值低 + 籌碼初動） | 報酬彈性高、需嚴設停損 | 楠梓電、樺漢、事欣科、和桐 |
| 趨勢驗證（領先指標） | 觀察 AI 資本支出真偽 | 漢唐、亞翔 |
| 獨立 Alpha（與景氣脫鉤） | 分散風險 | 藥華藥、萬海 |
| 觀察待確認（估值或籌碼存疑） | 需補資料、勿追高 | 景碩、康舒、系統電、台燿 |

**一句話定調**：本週精選池本質上是一張「AI 硬體擴產進度表」，資金已從晶片端外溢至代工、機電、被動元件全鏈條。操作上應「核心抱大型、彈性挑低估、嚴防循環股的高 PER 陷阱」，並務必以校正後的眼光看待 ROE 與 YoY 這兩個本期最易誤導的數字。
